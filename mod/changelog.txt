Version: 0.5.0
Date: 2026-10-30
  Features:
    - Factorio 2.1 support (crafter inventories, fluid box API, build modes).
    - Multi-planet: per-planet home, machine list and respawn.
    - Blueprint library synced from the bridge; place_blueprint, craft_for and connect_belt skills.
    - In-game AI panel (top-left button or Ctrl+Shift+A) and a debug event log.
    - build_power (steam block), build_assembler, build_red_cell, electric mining pairs; tend hauls plates to assemblers.
    - /ai-selftest (self-test maps only; see tests/ingame/run_selftest.py).
    - build_green_cell (green science from assembler units) and build_defense (gun turrets with ammo); tend loads turret ammo.
    - /ai-soak-start, /ai-soak-speed, /ai-soak-snapshot (self-test maps only; see tests/ingame/run_soak.py).
  Changes:
    - tend now looks after every AI-built machine on the surface, wires unpowered labs/assemblers to the grid, and picks up drills whose ore ran out.
    - craft_for reports hand-crafts to the force statistics so "craft a lab" research triggers fire for the AI.
    - State-changing commands are admin-only; chat orders need ai:, ai, or !ai.

Version: 0.4.2
Date: 2026-08-29
  Features:
    - Remote interface: get_chat lets an external harness poll the mod's
      chat ring buffer directly (no python bridge needed).
    - Remote interface: import_blueprint stages a blueprint string as entity
      ghosts at a position (build_blueprint, falling back to manual
      entity-ghost creation on Factorio 2.0 where the 1.x API path returns
      nothing).
    - Remote interface: export_blueprint captures a rectangle of the world
      to a blueprint string.
---------------------------------------------------------------------------------------------------
Version: 0.4.0
Date: 2026-07-16
  Features:
    - Remote interface: query/list_queries expose a read-only query registry
      (get_recipe, get_resource_patch, can_place, nearest_buildable,
      inspect_entity, get_enemies, get_character_state) for external callers,
      alongside the existing skill/primitive surface.
    - Remote interface: run_primitive lets external callers (e.g. an MCP
      client) invoke the same Tier-0 actions (place, mine, craft, set_recipe,
      insert, take, chat) the autonomous bridge LLM uses.
  Changes:
    - perception.lua: extracted describe_entity() so inspect_entity returns
      exactly what the autonomous router sees.
    - primitives.lua: exported placement_problem/DIRECTION_MAP for can_place.
